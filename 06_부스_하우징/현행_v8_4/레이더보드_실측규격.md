### ⚠️ Ø3.0 = M3에 여유 0
M3 나사 바깥지름이 정확히 3.0mm라 **틈이 사실상 없는 슬립핏**.
→ 하우징 보스 홀 위치가 ±0.1mm만 틀어져도 볼트 4개가 동시에 안 들어감.
→ **대책: 하우징 쪽 관통홀을 Ø3.4로 키워 공차를 전부 우리 쪽에서 흡수.**

### 사용할 홀 조합 (제안)
**H1 / H2 / H7 / H8** — Y스팬 48.5mm로 가장 넓어 비틀림에 가장 강함.

## 4. 하우징 설계에 바로 반영할 값

```python
board_L   = 55.000     # X
board_W   = 68.456     # Y   (v4의 65x50은 크기도 방향도 전부 틀렸음)
board_t   = 1.516
holes     = [(3.0, 57.124), (52.0, 57.124), (3.0, 8.624), (52.0, 8.624)]
hole_thru = 3.4        # 하우징 관통홀 (보드는 Ø3.0, 공차는 우리 쪽에서 흡수)
```

### 캐비티 여유 — 사방 균일하면 안 됨
| 방향 | 필요 여유 | 이유 |
|---|---|---|
| **−X (좌)** | **≥ 3.3 mm** | J3 커넥터가 3.29mm 돌출 |
| **+X (우)** | **≥ 1.3 mm** | J5 USB가 1.13mm 돌출 |
| ±Y | 1.5 mm | 돌출 없음 |

### 스탠드오프 높이
안테나면 최대 부품 = 4.62mm(TP12/13, 하단 탭 위치).
- v4의 `standoff_h = 6.0` → 여유 1.38mm. **간섭 없음. 그대로 사용 가능.**
- TP12/13은 하단 탭(Y<0)에만 있으므로, 그 구역만 국부 릴리프를 파면 더 낮출 수도 있음.

# [프레임 고정 방식 변경] 2026-07-22 — 관통볼트 채택(재국 제안)

## 결정
뚜껑↔3030 프로파일 고정을 **프린트 손잡이볼트 → 강철 관통볼트**로 변경.
- 뚜껑 형태 그대로. **나사산 구멍 → 민자 Ø6.5 관통홀(M6)** 로만 변경.
- **`clamp_screw.stl` 출력 불필요**(폐기 아님, 미사용).
- 회전방지: 새들 채널(30.6mm)이 프로파일을 양옆에서 꽉 물어줌 → **관통볼트 1개로 충분**(팽이회전 X).

## 근거(왜 더 나은가)
- 강철 이중전단 > 플라스틱 나사산 → **강성↑ = 진동/재현성 유리**(부스 재제작 목적과 부합).
- 업체가 뚫음 → 우리 작업↓. 기존 "재단·천공 전량 외주, 현장 볼트조립만" 워크플로와 일치.

## 업체 작업 지시 (간단)
1. 하우징(뚜껑)의 새들을 3030 상단보의 **목표 위치(레이더면 바닥 2300mm)** 에 끼운다.
2. 뚜껑에 **이미 뚫려있는 Ø6.5 관통홀을 드릴 가이드로** 그대로 사용해 3030 프로파일을 관통 천공.
   (별도 좌표 불필요 — 프린트 홀이 곧 위치)
3. **M6 볼트**를 관통 → 반대편 와셔 + 너트로 조임.
- 볼트 길이 ≈ 새들벽 4 + 프로파일 30 + 새들벽 4 + 너트 ≈ **M6 × 45 mm** 1개.
- (선택) 더 확실히 하려면 프로파일 길이방향으로 간격 두고 2홀. 새들이 회전 잡으므로 1개도 무방.

# [프레임 고정 최종] 2026-07-22 — 뚜껑은 센터딤플만, 업체가 관통드릴

**변경**: 뚜껑에 Ø6.5 관통홀을 뚫지 않는다. 대신 프로파일 단면 중심 높이에
**센터 딤플(바깥벽 양면, 깊이 2.5mm, 관통 안 함)** 만 남긴다.

**이유**:
- 사장님(업체) 볼트 규격(M5/M6/M8 등)을 우리가 모름 → 지름을 확정해 뚫으면 안 맞을 위험.
- 딤플이 **드릴 위치·높이를 안내** + 드릴날 미끄럼 방지. 지름은 업체가 자기 볼트로 결정.
- 벽을 관통 안 하니 새들 벽 강성 유지.

**업체 지시**:
1. 하우징 새들을 3030 상단보 목표위치(레이더면 2300mm)에 끼운다.
2. 뚜껑 바깥벽의 **딤플 자국을 중심으로**, 보유 볼트 규격에 맞는 드릴로
   **벽+프로파일+반대벽을 한 번에 관통**(한 번에 뚫어야 정렬 완벽).
3. 관통볼트 + 와셔 + 너트로 조임.

부품표의 "M6×45"는 예시일 뿐, **업체 보유 볼트에 맞춰 길이만 확보**(≈ 새들벽4+프로파일30+새들벽4+너트 ≈ 45mm 내외).
