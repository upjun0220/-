## 0. 결정 기록 — 왜 목재를 검토했고 왜 알루미늄으로 되돌렸나

**문제**
- 알루미늄 프로파일의 *자재 단가*가 비싸 보였고, 금속은 60GHz에서 강반사체라 레이더 클러터에 불리하다는 우려가 있었다.
- 동시에 2.4 m 높이에서 **상단 흔들림**을 최소화해야 한다(흔들리면 클러터맵 제거가 깨져 오탐 발생).

**검토 (목재안, 설계까지 완료)**
- 4×4 SPF(89×89) 기둥 + 랩조인트 + 전량 사전천공 **볼트 조립식 키트**로 설계 완료(설명서까지 제작).
- 장점: 60GHz 반사가 적고, 목재 감쇠가 커서 진동이 빨리 잦아든다.
- 단점: 무게 약 25 kg(알루미늄 ≈10 kg), 재단·천공 외주 필요, **하우징 마운트 재설계·재출력 필요**.
- 실제 비용 산출: **92,000 ~ 168,000원** (4×4 기둥 2개만 60,000원) → 알루미늄과 비슷하거나 오히려 비쌈.

**결정 (알루미늄 확정) — 근거**
1. **가격 이점 소멸**: 업체 견적 117,000원에 *가공+조립 포함*. 목재의 원가 우위가 사라졌다.
2. **일정**: 알루미늄은 즉시 제작 가능(완성품 수령). 목재는 수급·재단·자가조립으로 지연.
3. **하우징 재사용**: 기존 하우징이 **3030 새들 클램프** 방식이라 알루미늄에 그대로 물린다. 목재로 가면 마운트를 다시 설계·출력해야 한다.
4. **클러터 재평가**: 프레임은 **정지물**이므로 금속 반사도 거리게이팅+클러터맵(추가 비용 0)으로 대부분 제거된다. 클러터의 더 큰 변수는 재질이 아니라 **구조물 근접성(폭)** 이었다 → 폭을 1500으로 넓혀 대응한다.
5. **휴대성**: 알루미늄이 가볍다.

## 1. 프레임 (문 형태 2기둥 포탈 · 알루미늄 3030)

**문제**
- 2.4 m 높이 프레임 아래에서 사람이 낙상하는 실험을 해야 함 → 바닥·중앙을 가로지르는 부재가 있으면 안 됨.
- 프레임이 흔들리면 레이더가 진동 → 데이터 재현성 저하.
- 용접 불가(팀 역량).

**해결**
- **2기둥 포탈 프레임**, 바닥은 완전히 개방(낙상존 확보).
- 강성은 **금속(스틸) 조인트로**: ① 상단 두 코너에 큰 스틸 거셋(90°, 6 mm) ② 기둥–발 스틸 베이스 거셋 ③ 앞뒤 넓은 발 600 mm + 고무 엔드캡.
- 전 조립은 **M6 T너트 볼트**(용접 없음).

**주요 치수 (REV C, 폭 1.5 m로 갱신)**
- 기둥(수직): 3030, **2400** × 2
- 상단 가로보: 3030, **1440** × 1 (기둥 사이 1440, **전체폭 1500**)
- 하단보: **없음**(낙상존 개방)
- 발(앞뒤): 3030, **600** × 2
- 레이더 면 높이: 바닥에서 **2300**(= 소프트웨어 CEILING_H, 레벨링 풋으로 정밀 조정)

**폭을 1200 → 1500으로 넓힌 이유**
- 기둥이 낙상 지점에서 0.6 m밖에 안 떨어져 있어 구조물이 FOV 안으로 들어오고 다중경로 위험이 커진다.
- 측면 방향 낙상 시연 시 사람이 기둥에 닿을 여유가 부족하다.
- 단, 가로보가 길어지므로 업체가 강성 우려를 제기하면 **4040 또는 거셋 확대**를 상의한다.

**파일**: `알루미늄_제작도_업체용_1.5m.pdf` / `.png` (업체 제출용 1장), 소스 `gen_alu_sheet.py`

## 2. 레이더 하우징 (3D 프린팅) — ★v6 전면 재설계 (2026-07-22)

> v4(65×50 가정값·박스형·프린트 손잡이볼트)에서 **개방형(open-frame)** 으로 전면 재설계.
> 근거·상세는 `레이더보드_실측규격.md` 참조.

**문제**
- 케이블 자중이 마이크로USB 커넥터에 장력 → 데이터 패턴 손상(근본원인, 과거 1회 파손).
- 안테나(ODS) 앞에 금속/밀착 유전체가 있으면 60 GHz 차단·근거리 반사.
- v4는 보드 치수(65×50)가 **가정값이라 크기·방향 다 틀렸음.**

**해결 (v6)**
- 보드 규격을 **TI 공식 설계파일(SWRR165B.ZIP, Rev C STEP)에서 실측** → 눈대중 0.
- **개방형**: 바닥판·개구벽 전부 제거. 보드면 아래는 **코너 보스 4개 + 거싯**만 → 하방 FOV 전면 개방. (안테나 위치 ±2mm 불확실성이 개구벽 정렬 리스크가 되므로, 벽 자체를 없애 무관하게 만듦)
- **레이더 자체 M3 장착홀 4개**(코너 H1/H2/H7/H8)로 보스에 볼트 고정. 안테나면을 아래로 안착, **M3×12를 바닥쪽에서 위로 삽입 → 보드 뒷면 너트**.
- **관통홀 Ø3.4**: 보드 홀이 Ø3.0(=M3 여유 0)이라 하우징 쪽을 키워 공차 흡수.
- **USB 장력해소 3중**: ①크래들(커넥터 밑 받침) ②케이블타이 클램프(장력이 5핀 납땜에 안 감) ③서비스루프 훅.
- **J3(CAN 커넥터)는 라이트앵글 2.3mm라 보드 무개조**(인두·니퍼 불필요). 캐비티 좌측만 여유 크게(J3 3.29mm 돌출 회피).

**치수(v6)**: 외형 **67.4 × 77.5 × 24.5**, 보드 수용 **55 × 68.456 × 1.516**, PETG·벽 3라인·인필 25%. 검증: 트레이∩보드=0, ∩커넥터=0, watertight.

**파일**: `housing_tray.stl`, `housing_lid.stl`, `(출력용)housing_*.stl`, `gen_housing.py`, `레이더보드_실측규격.md`. (구버전 v4·v5는 `_v5_openframe_보류/`·`.bak_v4_box`)

### ★v7 재설계 (2026-07-23) — 실장 방향 정정 + USB 개방

**문제**
- v6는 "안테나면 아래" 실장을 의도했으나, 실제 출력물은 **안테나면 위(사진1)** 에서만 홀·USB가 맞음. 실제 오버헤드처럼 보드를 뒤집으면(안테나 아래·사진2) X가 거울반전돼 USB·클리어런스가 전부 반대편으로 감.
- v6 USB 크래들이 **사방 막힌 주머니** → 슬라이서가 그 빈 속을 인필 격자로 채워 사실상 막힘.

**해결**
- **Y축 미러(가로축 반사)**: 홀·부품 Y좌표를 보드 bbox 중심(y=26.396) 기준 반전. 홀 57.124→-4.33, 8.624→44.17. X는 불변 → 안테나 아래 실장 시 USB(5핀)가 **우상단**으로. `gen_housing.py`의 `MIRROR_Y` 플래그(True=v7, False=v6 복귀).
  - ※ 흔한 오해: '원점대칭(X·Y 모두 반전)'은 USB를 좌상단으로 보내 **틀림.** 뒤집기 = 거울(반사)이라 **Y만 반전**이 물리적으로 맞음. 홀 4개가 대칭이라 위치는 둘 다 꽂히고, 비대칭 부품(USB·헤더)으로만 방향이 갈림.
- **USB 크래들 제거** → 격자 막힘 해소, 완전 개방. 커넥터 keep-out만 유지. (장력방어는 v8에서 재설계)

### ★v8 개정 (2026-07-23, v7 실물 출력 확인 반영)

> v7 출력 → **보드 완벽 안착 확인.** 내부(캐비티·보스)는 "손대지 않는다" 원칙으로 불변. 아래 3건만 개정.

**문제 & 해결**
1. **코너 볼트(뚜껑↔트레이) 구멍이 작아 3mm 볼트가 안 들어감** (트레이 파일럿 Ø2.7 → 프린트 시 ~2.3).
   → **벽을 밖으로만 3→4mm 확장**(내부 캐비티 불변 → 보드 핏 유지, 외형만 +2mm씩·강성↑). 코너 기둥 Ø4.8→**Ø6.0**, 구멍 **Ø3.4 관통**. 조립은 **3mm 볼트 위→관통 후 바닥에서 M3 너트로 조임**(셀프탭 아님). 구멍 주변 살 1.3mm, 보드 최소 틈 0.98mm.
2. **프레임 고정 딤플이 마킹뿐** → 업체가 딤플 자리에 5.5mm로 뚫어 5mm 볼트가 잘 들어감을 확인.
   → 뚜껑 새들 딤플 2곳을 **실제 Ø5.5 X축 관통홀**로 모델에 반영(수동 드릴 불필요, 업체 결과와 동일).
3. **케이블타이 턱이 보드면 위(천장쪽)** → 아래로 늘어지는 케이블 당김을 못 잡음(무의미).
   → 턱을 **케이블 나오는 바닥쪽(커넥터 높이)으로 이동**: +X 벽을 바닥까지 얇게 연장 + 케이블 통과구멍 + 타이슬롯 2개. 얇은 판+관통이라 격자 막힘 없음(차있음/비어있음 단면으로 검증 완료).

**치수(v8)**: 외형 **69.4 × 79.5 × 24.5**(뚜껑 …×29.0). 내부 수용은 v6·v7과 동일. 검증: watertight·단일 바디·퇴화면 0·보드 간섭 0.

### ★v8.1 수정 (2026-07-25, 출력 전 검증에서 발견) — v8 타이앵커 결함 3건

> **v8은 출력하면 안 된다.** 3번 개정(케이블타이 턱)에 결함이 겹쳐 있었다. 트레이만 수정, 뚜껑은 v8과 동일.

**문제 & 해결**

1. **마이크로USB 플러그가 안 꽂힘 (치명)**
   v8은 +X벽을 통짜로 z0~5까지 내리고 **5.0 × 3.2 mm 창**만 뚫었다. 그 벽이 **J5 커넥터 정면 0.97 mm 앞**에 선다.
   USB 2.0 Micro-B **플러그 쉘 규격이 6.85 × 1.80 mm**(하우징 ~8×3, 오버몰드 ~11×5.5)이므로 **금속 쉘조차 못 지나간다.** 창이 J5 리셉터클 몸체 폭(8.20)보다도 좁았다.
   v7은 이 구간이 통째로 비어 있어서 조립이 됐던 것 → **v8에서 새로 막은 셈.**
   → **커넥터 정면은 폭 12 mm · z 0~5 전높이로 완전 개방**(v7과 동일한 진입로 복구). 앵커는 창 -Y쪽 기둥 하나로 몰았다.

2. **케이블타이 슬롯이 '닫힌 슬롯'이 아니라 끝이 터진 U자 노치**
   립 Y폭 12.0 에 슬롯 중심 jy±5.0 · 슬롯폭 2.2 → 필요 반폭 6.1 > 6.0 으로 **0.1 mm 모자라** 양끝이 뚫려 있었다(단면적 40.44 mm² = 48 − 2×(2.1×1.8) 로 확인). 타이가 끝으로 빠져 **장력 차단이라는 목적 자체가 무효.**
   → 슬롯을 기둥 안쪽에 배치, 주변살 **끝 1.5 / 사이 2.0 / X방향 1.0 mm** 확보한 폐합 슬롯.

3. **슬롯 단면이 케이블타이보다 작음**
   v8 슬롯 1.8 × 2.2 mm. 부품표의 **3 mm 케이블타이는 폭 ~3.4 × 두께 ~1.1** 이라 물리적으로 안 들어간다(프린트 수축까지 감안하면 더 좁아짐).
   → **2.0 × 4.0 mm** 로 확대, 간격 6.0 mm 로 2개.

**타이 사용법**: 슬롯1 ↓ → 하부 개방공간 → 슬롯2 ↑ → 케이블 위로 넘겨 결속. 루프가 기둥살+케이블을 함께 감아 당김 장력이 J5 납땜부 앞에서 끊긴다.

**검증(v8.1)**: watertight · 단일 바디 · 퇴화면 0 · winding 일관 / **플러그 경로(Y 50~61, Z 0.3~4.9, X 56.2~70) 간섭점 0** / 창 실측 폭 12.00 mm · 전높이 개방 / 타이슬롯 2곳 모두 폐합(2.00 × 4.00 실측) / 트레이 ∩ 보드 = ∩ J5 = ∩ J3 = **0.0000 mm³** / 외형·볼트홀 좌표 v8과 동일.

**파일(v8.1)**: `(출력용)housing_tray_v8_1.stl`, `(출력용)housing_lid_v8_1.stl`, **`HOUSING_BOX_PETGHF_v8_1.3mf`**, 검증 렌더 `tie_anchor_v8_1.png` / v8 결함 근거 `v8_ISSUE_usb_block.png`. 소스 백업 `gen_housing.py.bak_v6_prezflip`·`.bak_v7`.

### ★★v8.2 수정 (2026-07-26) — v6~v8 공통 결함: +X 벽이 USB 플러그를 막고 있었다

> **v8.1까지 전부 출력 금지.** 실물 사진 + USB-IF 규격 대조로 **v6·v7·v8 모두에 있던 근본 결함**을 찾았다. v7 출력 때 검증한 건 "보드 안착"이지 **USB 삽입이 아니었다.**

**문제 — 벽 자체가 플러그를 막는다**

| 항목 | 값 | 출처 |
|---|---|---|
| Micro-B 플러그 **금속 쉘** | 6.85 (+0.02/−0.06) × 1.80 (+0.02/−0.08) mm | USB 2.0 규격(전 제품 동일) |
| Micro-B **오버몰드 규격 상한** | **10.6 × 8.5 mm** | Micro-USB 규격 §3.5·§4.5.2 |
| 실제품 예시(Molex) | 10.8 × 6.4 × 길이 25.6 mm | 제조사 데이터시트 |
| **오버몰드 앞면 위치** | **보드 끝선 x ≈ 55.0** | **실물 사진 확인** |

- 플러그 축 높이 z = 3.64 (커넥터 2.28~5.00의 중심)
- 오버몰드 윗면 = z **6.84**(실제품) ~ **7.89**(규격상한)
- 그런데 트레이 +X 벽은 x 57.1~61.1 · **z 5.0 부터** 시작 → **1.8~2.9 mm 가 벽에 걸려 플러그가 끝까지 안 들어간다**
- 오버몰드 앞면이 보드 끝선까지 오므로 벽 4 mm 를 **반드시 관통**해야 한다. 우회로 없음.

**해결**

1. **+X 벽에 USB 개구부 신설** — Y **11.5 mm** × Z **5.0~8.5**, 벽 전관통. 지붕은 **45° 게이블**이라 수평 브리지가 없어 서포트·막힘이 생기지 않는다. 규격 상한 오버몰드(10.6 × 8.5)까지 통과.
2. **+Y 외벽만 4 → 6 mm 확장** (외형 Y 79.5 → **81.5**). 개구부에 필요한 반폭이 5.75 인데 코너 볼트기둥(Ø6, OY1−3) 때문에 4.61 밖에 안 나왔다. 기둥은 **-X 로도 못 옮긴다**(x < 58.1 이면 보드와 충돌 — 현 위치가 이미 한계). 벽을 2 mm 밀어 기둥을 개구부 밖으로 뺐다. **캐비티는 불변** → 보드 핏 그대로.
3. **하우징 케이블타이 앵커 폐지** (`TIE_ANCHOR=False`). 하우징은 3030 프로파일에 물리고 **케이블은 프로파일에 타이로 결속**한다. 플러그에서 30 mm 거리에 프로파일이 있어 케이블 자중이 커넥터에 도달하지 않는다 — 하우징 안에 앵커를 넣는 것보다 확실하고, **안테나면 아래에 구조물이 추가되지 않아 FOV·근거리 산란에도 유리**하다.

**검증(v8.2)**: watertight · 단일 바디 · 퇴화면 0 / **규격상한 오버몰드(10.6 × 8.5) 및 실제품(10.8 × 6.4) 통과경로 간섭 0**(x 55.2~72 전 구간 격자 샘플링) / 개구 상단 폭 단조감소 = 브리지 없음 / 코너기둥 여유 0.86 mm / 코너 볼트홀 4곳 트레이·뚜껑 일치 / 트레이 ∩ 보드 = ∩ J5 = **0.0000 mm³** / 1층 접지 4개 섬 304 mm².

### ★v8.3 (2026-07-26) — 장력 앵커 복원. 단 '선반'이 아니라 '타이'

**질문**: 개구부만 뚫고 아무것도 안 두면 케이블 힘을 전부 J5가 받는 것 아닌가? → **맞다.** 앵커가 없으면 하중 경로가 J5 납땜부 하나뿐이다. 오버몰드는 커넥터에서 25.6 mm 뻗은 강체 캔틸레버라 힘이 모멘트로 증폭돼 들어간다.

**그런데 '받치는 선반'은 넣을 자리가 없다**

| 오버몰드 | 하면 z | 하우징 바닥면(z=0)과의 틈 |
|---|---|---|
| 실제품 6.4 mm | **+0.44** | 0.44 mm |
| 규격상한 8.5 mm | **−0.61** | 바닥면보다 0.61 mm 아래로 내려감 |

플러그 축이 z=3.64 라 오버몰드 밑면이 이미 하우징 바닥면에 붙어 있다. 선반은 바닥면보다 더 내려가야만 가능 → 안테나면 아래 구조물이 늘어난다.

**애초에 막아야 할 하중이 다르다 (정량)**

- 케이블 자중 30 g(1 m) × 모멘트팔 25.6 mm = **7.4 mN·m**
- USB Micro 규격 §6.7: 15 mm 지점 **25 N 까지 무손상**(= 375 mN·m), 50 N 에서 플러그 파손
- → 자중은 무손상 한계의 **2.0 %**. **정적으로 매달리는 것만으로는 안 부러진다.**
- 25 N(≈2.5 kg)을 만들려면 낚아채기·발에 걸림·보드 무게가 케이블에 실리는 상황이어야 하고, 이는 과거 파손 정황("레이더를 제대로 고정 못한 상태")과 일치한다.
- **결론**: 눌러 받치는 선반이 아니라 **묶는 타이**가 맞는 대책.

**앵커 2곳 — 둘 다 플러그 봉투(Y 50.1~60.9 / Z ≤ 7.89) 밖이라 아무것도 안 막는다**

| | 위치 | 사양 | 역할 |
|---|---|---|---|
| **(a) 하부 타이패드** | -Y, y 36.51~49.51 · z 0~5 · x 57.1~61.1 | 닫힌 Z관통 슬롯 **2.0 × 4.0** × 2 (간격 6.0) | 케이블 나오자마자 결속. **1차** |
| **(b) 상부 벽슬롯** | +X 벽, y 52.5/58.5 · z 16~20 | X관통 슬롯 **2.0(Y) × 4.0(Z)** × 2 | 프로파일로 올라가는 **서비스 루프**를 하우징에 고정. **2차** |

- (a) 오버몰드 봉투와 이격 **0.60 mm**, 주변살 끝 1.5 / 사이 2.0 / X방향 1.0 mm. 코너 보스 거싯과 붙어 베드 접지도 늘어남(304 → 330 mm²).

**검증(v8.3)**: watertight·단일 바디·퇴화면 0 / **오버몰드 규격상한(10.6×8.5)·실제품(10.8×6.4) 통과경로 간섭 0**(앵커 추가 후 재검증) / 하부 슬롯 2곳 폐합 실측 2.00 × 4.00 / 상부 슬롯 2곳 X관통 확인, 상하 벽 solid / 코너 볼트홀 4곳 일치 / 트레이 ∩ 보드 = **0.0000 mm³**.

### ★v8.4 (2026-07-26) — v8.3 앵커 2곳 모두 '쓸 수 없는 구멍'이었음

> 슬라이서 화면을 보고 "이 앵커를 어떻게 쓰라는 거냐"는 지적에서 발견. 검증 결과 **둘 다 타이가 못 지나가는 구멍**이었다.

**문제**

1. **하부 패드 슬롯 — Z관통이 아니라 막힌 구멍**
   Z방향으로 뚫었는데 슬롯 바로 위가 **+X 벽(z 5~24.5)** 이라 z=8.6 에서 죽는다. **아래로만 열린 맹공**이라 타이가 통과할 수 없다.
2. **상부 벽슬롯 — 캐비티 내부로 나옴**
   벽 4 mm 만 관통해서 안쪽 끝이 **뚜껑 덮으면 밀폐되는 캐비티**로 나온다. 보드·뚜껑 조립 **전에** 미리 꿰어놔야만 쓸 수 있고, 교체하려면 뚜껑을 열어야 한다. → **폐지.**

**해결 — 슬롯 방향을 Z관통 → X관통 으로**

하우징 바닥(z<5)은 사방이 열려 있으므로, 패드를 **X방향(두께 4 mm)** 으로 뚫으면 양쪽이 모두 개방된다.

- **바깥쪽** x > 61.1 = 공중
- **안쪽** x < 57.1 = 보드 밑 개방공간

둘 다 **하우징 아래에서 손이 닿는다.** 보드·뚜껑을 다 조립한 뒤에도 케이블타이를 걸 수 있다.

| 항목 | 값 |
|---|---|
| 패드 | y 36.51~49.51 (13 mm) · z 0~5 · x 57.1~61.1 |
| 슬롯 | **X관통** 2.0(Y) × 3.8(Z), z 1.2~5.0, y중심 **40.01 / 47.51** |
| 주변살 | 바닥 1.2 / 패드 -Y끝 2.50 / 슬롯 사이 5.50 / 패드 +Y끝 1.00 mm |
| 플러그 봉투와 이격 | 0.60 mm (봉투 -Y끝 y=50.112) |

**사용법**: 타이를 바깥에서 슬롯 하나로 넣어 반대편 슬롯으로 빼고, 바깥쪽 루프에 케이블을 넣어 조인다. 안쪽 귀환 구간은 하우징 밑(z<0 개방공간)으로 살짝 늘어뜨리면 된다(보스 Y거싯이 x 50.5~53.0 에 있어 슬롯 출구에서 4.1 mm 여유). 슬롯 하나만 써서 패드 바닥살(1.2 × 2.0 mm, 인장 ≈100 N)에 감아도 된다.

**검증(v8.4)**: watertight·단일 바디·퇴화면 0 / **슬롯 2곳 X 전관통 확인**(벽 57.1~61.1 구간 solid 0, 양쪽 개방) / 오버몰드 규격상한·실제품 경로 간섭 **0** / 상부 벽슬롯 제거 확인 / 코너 볼트홀 4곳 일치 / 트레이 ∩ 보드 = **0.0000 mm³**.

## 4. 레이더 클러터·금속 반사 대응 (비용 0 우선)

**문제**
- 알루미늄 프레임은 60 GHz 강반사체. 특히 센서 바로 위 가로보가 근거리 반사원.

**해결 (싼 것부터 순서대로)**
1. **거리 게이팅(무료)** — 가로보는 센서에서 ≈0 m, 사람은 2.3 m 아래. 0.2~0.3 m 이내 반사를 잘라내면 가로보는 통째로 제거된다.
2. **클러터맵/빈방 등록(무료)** — 프레임은 정지물이라 정적 반사는 제거된다.
3. **배치(무료)** — 안테나를 하우징 안으로 넣어 가로보를 주 FOV 밖/그늘에 두고, 반사가 레이더로 되돌아오지 않게 한다.
4. **흡수폼(필요 시에만, 소량)** — 위 3개로도 허상/고스트가 보이면 **센서 근처 가로보 한 뼘**만 mmWave 흡수폼으로 덮는다. 프레임 전체에 바를 필요 없음.

**하지 말 것: 전파흡수 스프레이/페인트**
- 60 GHz 파장은 5 mm이고 흡수층은 최소 λ/4 ≈ **1.25 mm**가 필요하다. 스프레이 도막은 0.05~0.1 mm로 **10배 이상 얇아** 흡수가 성립하지 않는다.
- 도막을 발라도 아래 금속이 그대로라 반사가 유지된다. 비용 대비 효과가 없다.
