## Step 4 — 사람 시연 ①: 보행 오탐 0 확인 (~1분)
성준이 자유롭게 걸어다님 → 경보 0건, 상태바 `LIVE - NORMAL` 유지돼야 함.

## Step 5 — 사람 시연 ②: 낙상 (~5분)
매트로 낙상 → **즉시** 빨간 `FALL DETECTED` + 즉시조치 + 몇 초 내 매뉴얼 원문 2건 → [EVENT RESOLVED]로 해제. **5회 반복** (기록: 성공 횟수 __/5).

## Step 6 — 사람 시연 ③: 정지형(협착/감전) 2단계 무동작 타이머 ← **사람으로 시연**
1. 성준이 시야 안에서 정지(끼임 연기) → **15초**: 화면에 **노란 배너 + 카운트다운** 등장
2. **취소 데모**: 크게 움직임 → 배너 즉시 소멸 + 로그 `PRE-ALERT cleared` ("정당한 작업 정지는 오경보 안 냄" 포인트)
3. **경보 데모**: 다시 정지 → 15초 노란 배너 → 카운트다운 0 → **30초**: 빨간 `STATIONARY ANOMALY`(critical) + LOTO 즉시조치 → [EVENT RESOLVED]

멘트: "SIL2 인증 상용 안전 레이더(Inxpect)와 동일한 PRE-ALARM→ALARM 2단계 구조. 움직임 자체가 취소 버튼. 실배치 시 타이머 60~120초·Zone은 배전반 근처로 축소."

## Step 7 — 선풍기: 기계 진동 **데이터 수집** (~15분) ← **선풍기 용도는 이것뿐**
> 무동작/pre-alert는 Step 6(사람)이고, 선풍기는 진동 수집임. "사람이 선풍기 앞에서 떨기"는 폐기된 시나리오 — 없음.
> 진동 라이브 경보 시연은 오늘 수집분으로 문턱 확정 후 다음 세션부터.

1. live 창 닫기 → `python3 ~/radar_collect.py` (파서는 유지)
2. **사람 전원 시야 밖** + 선풍기만 시야 안, 회전 ON → 2초 후 `VIB(machine)` 버튼 → **10개** (위치/풍속 2~3가지)
3. **오염 검증**: 선풍기 **켠 채** 성준 보행 5개(`WALK`) + 낙상 3개(`FALL`) — 선풍기 도플러가 낙상 문턱(1.2) 침범 여부 확인용

## Step 8 — (선택) Llama 3.2 3B 설치 & 검증 — README "🧠 LLM 생성 복원 계획" 참조
버짓 분석 결과: 8B=OOM 확정(2.6GB 초과), **3.2:3b+num_ctx=1024=여유 1.1GB로 동작 가능**. 젯슨 실검증:

```bash
# [젯슨 터미널]
ollama pull llama3.2:3b                  # ~2GB
sudo tegrastats                          # [다른 터미널] RAM 감시 (7500/7620 근처 = 위험)
ollama run llama3.2:3b "낙상 사고 초동 조치 3가지를 한국어로"
```
통과 기준: 4~10초 내 응답 + RAM 한계 미도달 + 마우스 안 멈춤 → `radar_live_full.py` 상단 `USE_LLM_SUMMARY = True`로 변경 후 재실행. 실패 시 False 유지(시연 영향 0).

## 무동작 타이머 / PRE-ALERT 기대 동작 사양 (7/3 최종)

```
[걸어 들어옴] -> [정지]                       ← 진입(이동) 없으면 타이머 자체가 안 열림
      0s ───────────── 15s ──────────────────── 30s
      타이머 시작       노란 배너+카운트다운         빨간 STATIONARY ANOMALY
                       (움직이면 자동 소멸)         (critical, latch, 수동해제)
```
- **반드시 걸어 들어온 뒤 8초 안에 정지해야 타이머가 시작됨** (고스트/빈방 오탐 원천 차단 설계)
- 생체 하한(ds>0.10) + 위치 앵커(0.8m) + 히트비율(65%) + 클러터 스팟 2개 마스크 적용
- 경보 1회 발생 후엔 다시 움직였다가 정지해야 재무장됨 (진입 게이트)
- 이탈 0.5초 용인 / 사람 사라지면 3초 내 리셋 / 다른 경보 latch 중엔 표시 억제(RESOLVED 먼저) / `MAINT_MODE=True`면 억제
- 시뮬 검증: 빈 방 10분 0건(고스트 40% 악화 조건 포함), 걸어들어와 정지 시 정지 후 ~15s/30s 발화
