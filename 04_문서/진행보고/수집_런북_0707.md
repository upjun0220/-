## 2. 수집 방법 (버튼: FALL / WAVE / WALK / NORMAL / FAST-SIT ...)

**동작을 하고 → 그 "직후" 해당 버튼 클릭** → 직전 2초가 라벨과 함께 저장됨.

### 목표 수량 (4인 합계)
| 라벨 | 방법 | 목표 |
|---|---|---|
| **FALL** | 넘어짐 → **바닥 닿는 즉시 버튼** (누워있지 말 것) | 인당 10~15개 → **합계 40~60** |
| **WAVE** | 서서 팔 크게 상하로 흔들며 → 버튼 | 인당 8~10개 → **합계 30~40** |
| WALK | 걸어다니다 → 버튼 | 인당 3~5개 |
| NORMAL | 가만히 서있기 → 버튼 | 인당 3~5개 |

### 체형 다양성 (핵심)
- **4명이 각자 위 동작 반복.** 키/체구 다른 사람일수록 좋음 (RF가 체형차를 학습).
- 사람 바뀔 때 특별한 조작 불필요 — 그냥 다음 사람이 이어서 하면 됨 (전부 같은 파일에 누적).
- 낙상 방향(앞/옆/뒤), 속도도 다양하게 섞으면 더 좋음.

### 주의
- FALL은 **매번 진짜 넘어지는 동작**을 담아야 함. 앉기·주저앉기 말고 "쓰러짐".
- 버튼 클릭이 늦으면(2초 지나면) 동작이 창을 벗어남 → 동작 끝나고 **1초 안에** 클릭.
- 화면 하단 카운트(예: `FALL saved (12/10)`)로 몇 개 모았는지 확인.
