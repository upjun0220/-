# 감전(electric_shock_risk) 판별 유지 근거

> 작성 배경: 감전 시나리오를 협착과 겹친다는 이유로 제거하자는 의견에 대한 기술적 반론  
> 근거: Radar-Guard 팀 개발 과정 기술 검토 내용 기반

---

## 1. 결론부터

**감전 판별을 제거하면 안 된다.**

이유는 단순하다. 우리 시스템의 주요 배치 환경이 **변전실(Zone A)** 이고, 변전실에서 가장 유력한 사고가 감전이다. 오분류가 우려된다면 제거가 아니라 **분류 로직 개선**이 정답이다.

---

## 2. "협착이랑 겹친다"는 주장의 실제 원인

현재 `classify_event()` 코드는 **1D FFT 주파수만 보고 판단**한다.

```python
# 현재 분류 로직 (주파수 하나로만 구분)
if pl_ratio > 0.15 and dual_band > 0.10:   → 감전
elif 25 < dom_freq <= 40:                   → 협착
```

이 방식의 한계는 명확하다.

- 목데이터 합성 시 랜덤 노이즈가 주파수 경계를 흐린다
- **공간 정보(XYZ 위치, 속도 벡터)가 전혀 없다**
- 시간 축 정보(어떤 순서로 패턴이 나타났는지)가 없다

즉, 감전과 협착이 겹치는 건 **감전 판별 자체의 문제가 아니라 현재 피처가 부족해서 생기는 문제**다.

---

## 3. 실제 신호에서 감전과 협착은 명확히 다르다

### 시간 패턴 비교

| 구분 | 감전 | 협착 |
|------|------|------|
| 시작 방식 | 접촉 즉시 위치 고정 | 장비 방향으로 접근 후 접촉 |
| 진동 특성 | 50Hz 불수의 근육 경련 (전류 주파수) | 회전체 RPM 주파수 (28~32Hz) |
| 지속 패턴 | 접촉 중 진동 **계속 유지** | 압박 신호 지속 |
| 이후 변화 | 천천히 쓰러지거나 유지 | 위치 고정 |
| Z축 변화 | 거의 없거나 느리게 감소 | 없음 |

협착은 **접근 궤적이 먼저 있고**, 감전은 **처음부터 위치가 고정된 채 진동**한다.  
주파수 스냅샷 하나만 보면 겹쳐 보이지만, 시간 흐름 전체를 보면 전혀 다른 패턴이다.

### 주파수 비교

| 구분 | 감전 | 협착 |
|------|------|------|
| 지배 주파수 | **50Hz** (한국 전력선 주파수) | 28~32Hz (회전체) |
| 추가 성분 | **63Hz 동시 존재** (dual_band) | 없음 |
| 원인 | AC 전류 → 근육 경련 | 기계 회전 |

50Hz + 63Hz가 **동시에** 존재하는 건 감전 특유의 패턴이다.  
협착(회전체)에서 이 두 대역이 동시에 강하게 나타날 물리적 이유가 없다.

---

## 4. 현재 코드가 겹치는 건 피처 부족 때문이다

현재 `extract_features()`가 반환하는 것:

```python
# 현재: 64개 FFT 주파수 크기값만 반환
return mag[:feature_size]
```

실제 mmWave 레이더가 출력하는 것:

```
(x, y, z, doppler_velocity, intensity) × N개 포인트
```

**위치(XYZ)와 속도 벡터가 완전히 버려지고 있다.**  
이 정보를 살리면 두 시나리오의 구분이 명확해진다.

```
감전: centroid 고정 + 50Hz 미세진동(velocity 분포) + Z 변화 없음
협착: centroid가 장비 방향으로 이동 → 갑자기 멈춤 + 지속 압박
```

---

## 5. 당장 적용 가능한 해결책: Zone 사전 확률

복잡한 모델 수정 없이도 오분류를 줄이는 방법이 있다.

```python
# Zone A(변전실)에서는 감전 우선 판별
if zone == "A" and pl_ratio > 0.08:
    return electric_shock_risk

# Zone B(가공실)에서는 협착 우선 판별
if zone == "B" and 25 < dom_freq <= 40:
    return pinching
```

변전실에 **회전 기계가 있을 이유가 없다.**  
협착은 가공실(Zone B)에서 발생 확률이 높고, 변전실(Zone A)에서의 이상은 감전 가능성이 압도적으로 높다.  
Zone 정보를 쓰면 같은 주파수 패턴이 와도 맥락에 맞게 판별된다.

---

## 6. 감전을 제거했을 때의 실제 문제

변전실에서 작업자가 감전됐는데 시스템이 "협착"으로 분류하거나 "정상"으로 넘어간다면:

- 자동 차단기(재국 파트)의 대응 명령이 완전히 달라진다
- 감전: **즉시 전원 차단(POWER_CUT, 50ms)** 이 맞는 대응
- 협착 오분류 시: **회전체 정지(MACHINE_STOP, 100ms)** 명령 → 변전실에서 의미 없음
- 미탐지 시: 아무 대응 없음 → 최악의 결과

감전은 **전류가 흐르는 동안 계속 위험**하다. 빠른 전원 차단이 생명을 구한다.  
이 시나리오를 제거하면 시스템이 가장 중요한 기능을 잃는 것이다.

---

## 7. 개선 로드맵

제거 대신 아래 순서로 개선하는 것이 맞다.

**단기 (지금 바로 가능)**
- Zone A에서 감전 우선 판별 로직 추가 (코드 5줄)
- `dual_band` 임계값 튜닝

**중기 (모델 개선)**
- Point Cloud 기반 피처 추가 (x, y, z, doppler, intensity)
- 시간 축 피처 추가 (centroid 이동 궤적, Z 변화 속도, 진동 지속 시간)
- 2차 분류기 추가 (Random Forest 또는 2-layer LSTM)

**장기 (실제 데이터)**
- 젯슨에서 실제 레이더 데이터 수집 후 재학습
- 보조 센서 융합 (전류 누설 센서 or EMF 센서) 검토

## 요약

| 주장 | 사실 |
|------|------|
| "감전과 협착이 겹쳐서 뺀다" | 겹치는 건 피처 부족 때문, 감전 자체의 문제가 아님 |
| "주파수로 구분 불가" | 50Hz + 63Hz dual_band는 감전 특유 패턴, 현재도 구분 시도 중 |
| "제거가 더 깔끔하다" | 변전실(Zone A) 배치 환경에서 감전 미탐지는 시스템 자체가 목적을 잃음 |
| "오분류가 문제다" | Zone 사전 확률 + Point Cloud 피처 추가로 해결 가능 |

**감전 판별 제거는 문제 해결이 아니라 문제 회피다.**
