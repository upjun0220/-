## 핵심 개념 정리

| 개념 | 설명 |
|------|------|
| Document Loader | PDF, TXT, CSV 등 다양한 형식의 문서를 LangChain이 처리할 수 있는 형태로 불러오는 모듈 |
| Chunking (청킹) | 긴 문서를 LLM이 처리할 수 있는 적절한 크기의 조각으로 나누는 작업 |
| chunk_size | 한 청크의 최대 글자 수. 너무 크면 검색 정밀도 저하, 너무 작으면 문맥 손실 |
| chunk_overlap | 청크 간 겹치는 글자 수. 문맥이 끊기는 것을 방지하기 위해 설정 |
| Embedding | 텍스트 청크를 벡터로 변환하는 과정. 여기서는 OpenAI `text-embedding-3-small` 모델 사용 예정 |
| 코사인 유사도 | 두 벡터 간의 방향 유사도를 측정 (1에 가까울수록 유사). 검색 시 쿼리와 가장 가까운 청크를 찾는 데 사용 |

## 실습 예정 코드 스니펫

```python
from langchain_community.document_loaders import PyPDFLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import PGVector

# 1. 문서 로드
loader = PyPDFLoader("safety_manual_SOP.pdf")
documents = loader.load()

# 2. 청킹
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=50
)
chunks = splitter.split_documents(documents)

# 3. 벡터 DB에 적재
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vectorstore = PGVector.from_documents(
    documents=chunks,
    embedding=embeddings,
    connection_string="postgresql://user:password@localhost:5432/radar_guard"
)

# 4. 유사도 검색 테스트
results = vectorstore.similarity_search("낙상 발생 시 초동 조치", k=3)
for doc in results:
    print(doc.page_content)
    print("---")
```
