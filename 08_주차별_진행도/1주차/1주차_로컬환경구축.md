## 핵심 개념 정리

| 개념 | 설명 |
|------|------|
| Docker | 앱과 환경을 컨테이너로 묶어 어디서든 동일하게 실행할 수 있게 해주는 도구 |
| PostgreSQL | 오픈소스 관계형 DB. pgvector 익스텐션을 통해 벡터 저장/검색 기능 추가 가능 |
| pgvector | PostgreSQL에서 고차원 벡터를 저장하고 코사인/L2 유사도 검색을 지원하는 익스텐션 |
| 벡터 임베딩 | 텍스트를 수백 차원의 숫자 배열로 변환한 것. 의미가 비슷한 문장은 벡터 공간에서 가까운 위치에 놓임 |

## 실습 예정 코드 스니펫

```sql
-- pgvector 익스텐션 활성화
CREATE EXTENSION IF NOT EXISTS vector;

-- 벡터 컬럼을 포함한 테이블 생성 (1536차원 = OpenAI text-embedding-3-small 기준)
CREATE TABLE safety_manual (
  id SERIAL PRIMARY KEY,
  content TEXT,
  embedding VECTOR(1536)
);

-- 코사인 유사도 기반 검색 예시
SELECT content
FROM safety_manual
ORDER BY embedding <=> '[쿼리 벡터]'
LIMIT 3;
```
